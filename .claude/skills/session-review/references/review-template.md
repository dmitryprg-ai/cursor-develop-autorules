# Session Review Template

## Full Review Format

```markdown
## SESSION REVIEW

### 1. Planned vs Actual
| Request | Expected | Actual | Gap |
|---------|----------|--------|-----|
| [request] | [expected] | [done] | [gap] |

### 2. Where I Cut Corners
| Moment | Should Have Done | Did Instead | Impact |
|--------|-----------------|-------------|--------|
| [when] | [correct action] | [what I did] | [consequence] |

### 3. Protocol Compliance
| Protocol | Status | What Was Missed |
|----------|--------|-----------------|
| Challenge (4 questions) | yes/no/partial | [what] |
| Cross-check (open files) | yes/no/partial | [what] |
| Confidence calculation | yes/no/partial | [what] |

### 4. Patterns Identified
- [Pattern 1]: happened N times in this session
- [Pattern 2]: similar to error from [date]

### 5. Improvement for Backlog

## IMPROVEMENT #N: YYYY-MM-DD (Short name)

**Source:** Session review after [task]
**Problem:** [what went wrong]
**Root Cause:** [from analysis]
**Proposed change:** [what to add to instructions]
**File:** `.claude/rules/[file].md`
**Priority:** High/Medium/Low
**Status:** Backlog
```

## Quick Review (for short sessions)

```markdown
## QUICK REVIEW

**Duration:** ~X minutes
**Tasks completed:** N
**Issues encountered:** [brief]
**Key learning:** [one sentence]
**Improvement needed:** [yes/no — if yes, record to backlog]
```
