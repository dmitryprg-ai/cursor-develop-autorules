# 📖 КАК РАБОТАТЬ С CURSOR RULES

## Краткий ответ

**НЕТ, тебе НЕ нужно писать "используй core-master.mdc".**

Файлы с `alwaysApply: true` применяются **АВТОМАТИЧЕСКИ**.

---

## Как это работает

```
Твой запрос 
    ↓
core-master.mdc (автоматически)
    ├── Определяет сложность 🟢/🟡/🔴
    ├── Выбирает протокол
    └── Требует DONE блок в конце
    ↓
protocol-*.mdc (по типу задачи)
    ↓
_base-*.mdc (forbidden, crosscheck, challenge — автоматически)
    ↓
DONE блок (обязательно в конце ответа)
```

---

## Структура ответа AI

Каждый ответ ДОЛЖЕН содержать:

```markdown
**Сложность: 🟢/🟡/🔴** — [причина]

## 📋 ПЛАН (для STANDARD/COMPLEX)
**Цель:** ...
**Файлы:** ...

[Выполнение...]

| Файл | Открыт | Проверен |  ← Cross-check
|------|--------|----------|

1. Как опровергнуть? → ...      ← Challenge
2. Все файлы открыл? → ДА/НЕТ
3. Edge cases? → ...

---
## ✅ DONE                       ← ОБЯЗАТЕЛЬНО
**Сложность:** 🟢/🟡/🔴
**Что сделано:** ...
**Проверки:** Cross-check ✅ | Challenge ✅ | Linter ✅
**Уверенность:** X% — ...
---
```

## 📏 Контроль размера файлов (v8.1)

`standard-file-size-limits-always.mdc` предотвращает "монолиты":

| Правило | Действие |
|---------|----------|
| Файл > 300 строк | План разбиения ПЕРЕД добавлением кода |
| Файл > 500 строк | ОБЯЗАТЕЛЬНО разбить |
| Разбиение | По бизнес-доменам, НЕ по техническим слоям |

### Лимиты:
- Routes/Controllers: 200/400 строк (soft/hard)
- Services: 250/500 строк
- React components: 200/400 строк

### Интеграция:
- `protocol-development.mdc` → ПРАВИЛО #6, шаг "Control File Size"
- `protocol-refactoring.mdc` → шаг "PREPLAN", "RULES FIRST"

## 📄 API Pagination (NEW in v9.0)

`standard-api-pagination-always.mdc` предотвращает бесконечные циклы:

| Правило | Описание |
|---------|----------|

| ДОПОЛНИТЕЛЬНО | Safety limits как защита |

## ⚛️ React Hooks (NEW in v9.0)

`standard-react-hooks-always.mdc` предотвращает React Error #310:

| Правило | Описание |
|---------|----------|
| Хуки | ВСЕГДА в начале компонента, ДО early returns |
| Условия | Хуки НЕ вызываются внутри if/else, циклов |
| Проверки | Данные проверять ВНУТРИ callback хука |

## 🧹 TechDebt Scan (NEW in v9.0)

Команда для поиска технического долга в конце сессии:

```
@rules_alone/techdebt Запусти поиск технического долга
```

**Что делает:**
- Сканирует файлы > 300 строк
- Ищет дублирующийся код
- Выявляет code smells
- Приоритизирует по Impact/Effort
- Записывает P0-P1 в backlog
